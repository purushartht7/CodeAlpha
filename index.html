2. Task 1: FAQ Chatbot — Architecture & Mathematical Modeling

Task 1 implements a deterministic, closed-domain conversational system. Rather than relying on black-box generative models prone to hallucinations and recurring API fees, it implements a vector space information retrieval engine.

Core Mathematical Formulations:

1. Smooth Inverse Document Frequency (IDF):

IDF(t) = ln((1 + N) / (1 + DF(t))) + 1

(Penalizes ubiquitous words across documents; gives high weight to discriminative terms).

2. Euclidean L2 Vector Normalization:

v_norm = v / sqrt(sum(v_i ^ 2))

3. Cosine Similarity (Dot Product of Normalized Vectors):

Cosine Similarity(u, q) = (u • q) / (||u|| * ||q||) = u_norm • q_norm

Confidence Threshold Logic: A dynamic acceptance threshold of 0.25 (25%) is enforced. Queries scoring below 0.25 trigger a polite out-of-domain fallback rather than delivering an irrelevant answer.

3. Task 2: AI Multi-Lingual Translation & Voice Synthesis

Task 2 delivers a resilient machine translation and accessibility utility covering over 130 global languages.

  • Dynamic Language Discovery: Live ISO language code resolution mapping 130+ languages.
  • Resilient Dual-Tier Execution: Features serverless API processing on Vercel backed by an automated client-side fallback to guarantee 100% translation uptime.
  • Zero-Disk Audio Synthesis: Uses in-browser Speech Synthesis (Web Speech API) and synchronized streaming, preventing temporary file accumulation and server memory leakage.
  • Clipboard Integration: One-click formatted code blocks for instantaneous copying.
